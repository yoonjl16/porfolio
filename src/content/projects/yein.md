## 개요

**2025 카카오 × 구름 시즌톤**에서 16팀으로 참가해 약 일주일 동안 만든 서비스입니다.

> "글을 쓰며 마음을 다스리는 필사, 지금 시작해 보세요."

필사는 마음을 차분하게 해 주지만, 혼자 하다 보면 쉽게 그만두게 됩니다. 예인은 **오늘의 문구 추천 → 손글씨 필사 → AI 분석 → 성장 보상 → 공유**로 이어지는 흐름을 만들어 필사를 꾸준히 하게 돕습니다.

## 주요 기능

- **오늘의 필사하기** — 매일 추천 문구를 받아 종이에 따라 쓰고, 사진을 업로드하며 그날의 감정(기쁨 · 평온 · 우울 등)을 고름
- **AI 분석** — 손글씨를 총점(100점)과 간격 · 일관성 · 길이 점수로 평가하고, 피드백과 강점을 알려줌
- **펫 키우기** — 꾸준히 필사하면 펫의 레벨이 오르고 진화
- **갤러리 · 랭킹 · 커뮤니티** — 다른 사람의 필사를 보고, 베스트 필사와 게시글을 공유

## 내가 한 일

2명의 프론트엔드 중 한 명으로, **로그인부터 필사 → 분석 결과까지 서비스의 핵심 흐름**을 맡았습니다. 기간 동안 전체 커밋 146개 중 76개를 작성했습니다.

- **카카오 로그인** — 카카오 OAuth 인가 코드 방식으로 구현. 로그인 요청 때 무작위 `state` 값을 만들어 `sessionStorage`에 저장하고, 콜백에서 돌아온 값과 비교해 **CSRF를 막았습니다**. 인가 코드는 백엔드로 보내 카카오 토큰을 서비스 액세스 토큰으로 교환하고, 토큰이 없으면 로그인 화면으로 보내는 처리를 페이지마다 넣었습니다
- **오늘의 필사 화면** — 추천 문구 API 연동, 드래그 앤 드롭 이미지 업로드와 미리보기, 감정 여러 개 선택 UI, `FormData`로 이미지와 감정 정보를 함께 제출
- **분석 결과 화면** — 총점과 항목별 점수를 막대 그래프로 보여주고, AI 피드백과 강점을 정리. "다시 도전"과 "완성" 버튼, 재도전 팝업으로 다음 행동을 이어지게 구성
- **로딩 · 소개 화면, 홈 · 마이페이지 개선** — AI 분석을 기다리는 동안 보여줄 로딩 화면과 서비스 소개 페이지를 만들고, 홈과 마이페이지 UI를 다듬음

## 협업과 배포

- 기능별 브랜치(`feature/Transcription` 등)와 Pull Request로 다른 프론트엔드 팀원과 동시에 작업
- Vercel로 배포하고, `/api` 요청을 백엔드 서버로 넘기는 rewrite를 설정해 브라우저 CORS 문제 없이 API를 호출

## 배운 점

- **짧은 기간일수록 핵심 흐름부터** — 일주일 안에 끝내기 위해 "필사 → 분석 → 결과" 흐름을 먼저 완성하고, 나머지 화면은 그 위에 얹는 순서로 작업했습니다.
- **인증은 화면이 아니라 흐름으로 설계해야 한다** — 로그인 화면만 만드는 게 아니라 state 검증, 토큰 교환, 토큰 만료 시 되돌려 보내기까지 이어져야 사용자가 막히지 않는다는 걸 배웠습니다.
