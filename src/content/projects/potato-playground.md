## 수상

- **2026 캡스톤디자인 경진대회 우수상** (사업단장상)
- **한국정보기술학회 2026 하계 종합학술대회 우수논문상** (동상) — 「MER 기반 실시간 표정 인식을 활용한 아동 사회성 향상 게임 시스템」 제1저자

## 문제

만 3~7세는 표정을 읽고 감정을 이해하는 능력이 자라는 시기입니다. 자폐 스펙트럼 장애(ASD) 아동은 이 부분에서 특히 집중적인 학습이 필요합니다. 하지만 감정 카드나 그림책 같은 기존 교구는 고정된 이미지뿐이라 아이가 감정을 맞게 표현했는지 **바로 알려줄 수 없었습니다**. 아이의 발달 상태도 보호자의 주관적인 관찰에만 의존했습니다.

## 해결

전면 카메라로 아이의 표정을 실시간으로 분석해 **표정만으로 진행하는 감정 학습 게임**을 만들었습니다.

- **감정 미러링** — 아이가 지은 표정을 AI가 인식해 거울처럼 바로 보여줍니다
- **표정 따라하기** — TTS로 미션("깜짝 놀란 토끼처럼 눈을 동그랗게 떠보아요!")을 내면 아이가 표정으로 답하고, AI가 정답 여부를 판정합니다
- **상황별 표정 짓기** — LLM이 일상 상황("친구가 장난감을 뺏어갔어요")을 제시하면 아이는 상황 이해 → 감정 추론 → 표정 표현의 3단계로 답합니다
- **캐릭터 도감 · 리포트** — 경험치와 레벨에 따라 캐릭터가 해금되고, 보호자는 감정별 정답률 차트를 볼 수 있습니다

## 내 역할

5인 팀의 팀장으로 프로젝트 일정과 범위를 관리했고, **AI 파이프라인 전체**(데이터셋 구성, 전처리, 모델 비교·학습, 앙상블, Flask 추론 서버)를 맡았습니다.

## 데이터

아동 미세 표정 데이터셋 **CMED**(아동 74명, 영상 10,924개)를 사용했습니다.

- **클래스 재구성** — 원본 7개 감정 중 fear는 19개, sad는 42개뿐이라 학습이 어려웠습니다. 그래서 아동 발달 관점에 맞춰 **긍정 · 부정 · 중립 · 놀람** 4개 클래스로 묶었습니다
- **프레임 추출** — 영상에서 1fps로 프레임을 뽑고, OpenCV Haar Cascade로 얼굴을 잘라 224×224로 저장했습니다. 영상 단위가 아닌 프레임 단위로 학습해 희귀 클래스의 샘플 수를 몇 배 늘렸습니다
- **누수 방지** — 같은 아이의 데이터가 학습과 평가에 함께 들어가지 않도록 **피험자 단위**로 학습 52명 / 검증 11명 / 테스트 11명으로 나눴습니다
- **불균형 대응** — 아래 표처럼 언더·오버샘플링을 하고, Gemini API로 부정·놀람 합성 이미지를 만들어 보충했습니다. WeightedRandomSampler와 클래스 가중치 손실도 함께 적용했습니다

| 클래스 | 원본 프레임 | 학습 프레임 | 처리 |
| --- | --- | --- | --- |
| 긍정 | 17,597 | 5,000 | 언더샘플링 |
| 부정 | 737 | 3,000 | 오버샘플링 + 합성 |
| 중립 | 39,138 | 6,000 | 언더샘플링 |
| 놀람 | 760 | 3,000 | 오버샘플링 + 합성 |

## 모델 선택

5개 모델을 같은 조건으로 비교했습니다.

| 모델 | 긍정 F1 | 중립 F1 | 특징 |
| --- | --- | --- | --- |
| ViT Base | 73.5% | 90.5% | 전역 특징 |
| EfficientNet-B0 | 72.1% | 85.7% | 경량 CNN |
| DINOv2 | 48.8% | 80.8% | 자기지도 학습 |
| Swin Transformer | 78.1% | 91.8% | 윈도우 기반 지역 특징 |
| ConvNeXt-Base | 77.5% | 91.3% | CNN 기반 텍스처 특징 |
| **Swin + ConvNeXt 앙상블** | **79.2%** | **92.2%** | 두 모델 상호 보완 |

Swin Transformer는 얼굴 근육의 미세한 움직임을 잘 잡고, ConvNeXt는 피부 텍스처와 색 변화를 잘 잡습니다. 이 둘을 **Weighted Soft Voting**으로 합쳤고, 가중치는 검증 셋 F1 macro를 기준으로 0.1 단위 그리드 탐색으로 정했습니다.

- **도메인 적응**: 성인 미세 표정 데이터셋 CASME II로 사전학습한 뒤 CMED로 파인튜닝
- **부분 파인튜닝**: 백본의 앞쪽 2개 stage는 고정하고, 뒤쪽 2개 stage와 커스텀 분류기만 학습
- **학습 설정**: AdamW (lr 1e-4) · CosineAnnealingLR · 50 epoch · Gradient Clipping · RTX 3060 12GB

## 결과

| 지표 | 값 |
| --- | --- |
| 검증 정확도 | Swin 83.37% · ConvNeXt 83.23% |
| 앙상블 Weighted F1 | **85.1%** |
| 긍정 / 중립 F1 | 79.2% / 92.2% |
| 부정 클래스 F1 (불균형 보완 전 → 후) | 2.3% → **19.7%** |

학습한 앙상블 모델은 Flask 서버로 서빙했습니다. 브라우저가 웹캠 프레임을 500ms마다 Base64로 보내면 서버가 감정과 클래스별 확률을 JSON으로 돌려줍니다. 이 결과는 Spring Boot 백엔드를 거쳐 게임 라운드 채점과 감정 로그(PostgreSQL)에 저장됩니다.

## 한계와 배운 점

- **소수 클래스 성능** — 부정·놀람은 원본 데이터가 중립의 1/50 수준이라 개선한 뒤에도 성능이 낮았습니다. 데이터 양이 모델 구조보다 성능에 더 큰 영향을 준다는 걸 수치로 확인했습니다. 다음에는 apex 프레임 중심 샘플링과 아동 데이터 추가 수집을 해 보고 싶습니다.
- **정서적 자율성** — "정답 표정"을 맞히는 구조에서는 아이가 실제로 느낀 감정 대신 보상을 위한 표정을 지을 수 있습니다. 그래서 여러 감정을 정답으로 인정하는 시나리오와 정답이 없는 자율 놀이 모드를 후속 과제로 정리했습니다.
- LLM API를 연동하는 데서 끝내지 않고 **목적에 맞는 AI 파이프라인을 직접 설계·학습·서빙**하면서, 모델 성능과 서비스 경험을 함께 고려하는 법을 배웠습니다.
